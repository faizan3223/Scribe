Scrobo AI Guides

These short guides help new users get value quickly and use AI responsibly.

1. Drafting a professional email

List your points as bullets first. Ask Scrobo for a formal draft, then edit names, dates, and numbers yourself. Never send text that still contains placeholders.

2. Debugging code

Open Code mode. Paste the minimum code that fails, the full error message, and your expected result. Ask for a corrected full function and a short explanation of the root cause.

3. Studying with AI

Ask for an explanation, then request five practice questions. Answer them yourself before revealing solutions. This builds understanding instead of copy-paste learning.

4. Image and creative prompts

Describe subject, style, lighting, and mood. Avoid asking for copyrighted characters you do not own. Use Imagine tools only for original or licensed ideas.

5. Privacy checklist

No passwords, no full card numbers, no private customer databases. Prefer Incognito for confidential drafts. Read the Privacy Policy before enabling optional cloud features.
